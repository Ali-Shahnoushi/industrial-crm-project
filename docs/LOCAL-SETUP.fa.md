# 💻 راهنمای راه‌اندازی و توسعه محلی پروژه در Laragon

پروژه در سیستم شما در مسیر `C:\laragon\www\part` به طور کامل راه‌اندازی، بیلد و شبیه‌سازی شده است.

---

## 🛠 مشخصات محیط محلی راه‌اندازی‌شده
* **PHP:** نسخه 8.4.26
* **Composer:** نسخه 2.11.1
* **Node.js:** نسخه 24.18.0
* **MySQL:** سرور MySQL 8.0.42 بر روی پورت 3306
* **Database Name:** `crm_part`
* **کاربر دیتابیس:** `root` (بدون رمز)

---

## 🚀 دستورات اجرای سریع در سیستم

### ۱. اجرای سرور بک‌اند لاراول
در یک ترمینال در ریشه پروژه دستور زیر را بزنید:
```bash
php backend/artisan serve --port=8000
```
آدرس API: `http://127.0.0.1:8000`

### ۲. اجرای سرور توسعه فرانت‌اند (Vite + React)
در یک ترمینال دیگر:
```bash
cd frontend
npm run dev
```
آدرس رابط کاربری: `http://localhost:5173`

## 📦 نحوه ساخت پکیج جدید برای هاست cPanel
هر زمان که کدهای فرانت‌اند یا بک‌اند را تغییر دادید و خواستید خروجی جدید برای هاست cPanel بسازید:
در PowerShell دستور زیر را اجرا کنید:
```powershell
powershell -ExecutionPolicy Bypass -File deploy/cpanel/build.ps1
```
بسته‌های فشرده‌شده `cpanel-public.zip` و `cpanel-private.zip` در پوشه `cpanel-release` ایجاد می‌شوند.
