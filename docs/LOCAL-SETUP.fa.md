# 💻 راهنمای راه‌اندازی و توسعه محلی پروژه (نسخه ۲.۳.۰)

پروژه در سیستم شما در مسیر `C:\laragon\www\part` به طور کامل راه‌اندازی، بیلد و شبیه‌سازی شده است.

---

## 🛠 مشخصات محیط محلی راه‌اندازی‌شده
* **PHP:** نسخه 8.4.26 (لارگون)
* **Composer:** نسخه 2.11.1
* **Node.js:** نسخه 24.18.0
* **MySQL:** سرور MySQL 8.0.42 بر روی پورت 3306
* **Database Name:** `crm_part`
* **کاربر دیتابیس:** `root` (بدون رمز عبور)

---

## 🚀 دستورات اجرای سریع در سیستم

### ۱. اجرای تک‌کلیکی با اسکریپت ویندوز (پیشنهادی)
کافی است فایل [`run-master.bat`](../run-master.bat) را در ریشه پروژه با دابل کلیک اجرا کنید:
- سرور بک‌اند به صورت خودکار روی `http://127.0.0.1:8000` اجرا می‌شود.
- سرور فرانت‌اند به صورت خودکار روی `http://127.0.0.1:3000` اجرا می‌شود.
- رابط کاربری به صورت زنده در دسترس قرار می‌گیرد.

### ۲. اجرای دستی در دو ترمینال مجزا

#### ترمینال اول — بک‌اند لاراول:
```bash
cd backend
php artisan serve --host=127.0.0.1 --port=8000
```
- آدرس پایه API: `http://127.0.0.1:8000/api/v1`
- مستندات زنده و تعاملی OpenAPI: `http://127.0.0.1:8000/docs/api`

#### ترمینال دوم — فرانت‌اند Vite + React:
```bash
cd frontend
npm run dev
```
- آدرس توسعه رابط کاربری: `http://localhost:5173`

## 🧪 اجرای تست‌های خودکار و کنترل کیفیت (QA)

### تست‌های بک‌اند (PHPUnit):
```bash
cd backend
php artisan test
```
*شامل ۱۸ تست خودکار (۱۷۲ Assertion) پوشش‌دهنده تبدیل تاریخ جلالی، سطوح RBAC، تراکنش‌های انبار، اعتبارسنجی مشتریان، پشتیبان‌گیری و مسدودسازی امنیتی.*

*اجرای اعتبارسنجی روی تمامی ۵۲ فایل کامپوننت با ۰ خطا و ۰ هشدار.*

## 💾 ویژگی‌های جدید نسخه ۲.۳.۰ در محیط محلی
1. **پشتیبان‌گیری و بازیابی داده‌ها:** با مراجعه به منوی **تنظیمات سامانه → پشتیبان‌گیری و بازیابی داده‌ها** (`/settings/backup`) می‌توانید وضعیت پایگاه داده را مشاهده کرده، خروجی SQL Dump و خروجی JSON پرونده‌ها را دریافت و تست بازیابی JSON را انجام دهید.
2. **فیلترهای جدید مشتریان:** در صفحه مشتریان (`/customers`) از چیپ‌های فیلتر سریع (همه، دارای دستگاه، بدون دستگاه، بالقوه، بالفعل، گارانتی فعال) و فیلتر کشویی چندمعیاره استفاده کنید.
3. **شماره سریال اختیاری:** در مودال تخصیص دستگاه به مشتری، می‌توانید فیلد شماره سریال را خالی بگذارید؛ ثبت دستگاه و کسر موجودی انبار بدون نیاز به سریال انجام می‌شود.

## 📦 نحوه ساخت پکیج جدید برای هاست cPanel

هر زمان که کدهای فرانت‌اند یا بک‌اند را تغییر دادید و خواستید خروجی جدید برای هاست cPanel بسازید:
در PowerShell دستور زیر را اجرا کنید:
```powershell
powershell -ExecutionPolicy Bypass -File deploy/cpanel/build.ps1
```
بسته‌های فشرده‌شده `cpanel-public.zip` و `cpanel-private.zip` همراه با شناسنامه بیلد در پوشه `cpanel-release/` ایجاد می‌شوند.
