# 📦 پوشه بسته‌های آماده نصب در cPanel (`cpanel-release`)

این پوشه به‌صورت **کاملاً خودکار توسط GitHub Actions** پس از اجرای موفق تمامی تست‌ها (Linter فرانت‌اند، تست‌های واحد و یکپارچه PHPUnit، تست‌های امنیتی و تست واقعی نصب روی MySQL) ساخته و بروزرسانی می‌شود تا نیازی به اجرای دستور بیلد روی سیستم محلی نداشته باشید.

---

## محتویات این پوشه

| نام فایل | کاربرد در هاست cPanel |
| :--- | :--- |
| **`cpanel-private.zip`** | **هسته خصوصی لاراول و پوشه `vendor`** — باید **بیرون از `public_html`** (مثلاً در مسیر `/home/USER/crm-private`) آپلود و Extract شود. |
| **`cpanel-public.zip`** | **فایل‌های عمومی فرانت‌اند React و نقاط ورود وب** — باید **داخل `public_html`** (یا پوشه دامنه/ساب‌دامنه) آپلود و Extract شود. |
| **`SHA256SUMS`** | امضای دیجیتال SHA-256 هر دو فایل زیپ جهت اطمینان از سلامت کامل فایل‌ها. |
| **`build-info.txt`** | گزارش زمان دقیق ساخت، نسخه PHP/Node و هش فایل‌های قفل وابستگی‌ها. |
| **`v2.0.0_cpanel_migration.sql`** | اسکریپت کمکی SQL (اختیاری) برای ارتقای مستقیم دیتابیس از طریق تب Import در `phpMyAdmin`. |

---

## راهنمای سریع نصب اولیه (۲ دقیقه‌ای — بدون نیاز به SSH)

1. در **File Manager** سی‌پنل، یک پوشه خصوصی بیرون از `public_html` بسازید (مثلاً `/home/USER/crm-private`) و فایل **`cpanel-private.zip`** را در آن آپلود و **Extract** کنید.
2. فایل **`cpanel-public.zip`** را داخل **`public_html`** آپلود و **Extract** کنید.
3. فایل `public_html/private-path.php` را ویرایش کرده و مسیر دقیق پوشه خصوصی مرحله ۱ را در آن قرار دهید:
   ```php
   <?php
   return '/home/USER/crm-private';
   ```
4. در مرورگر آدرس `https://YOUR-DOMAIN.com/install.php` را باز کنید، مشخصات دیتابیس MySQL و حساب مدیر ارشد را وارد نمایید تا نصب خودکار انجام و نصب‌کننده قفل شود.

---

## راهنمای سریع بروزرسانی نسخه قبلی (با حفظ ۱۰۰٪ داده‌ها — بدون SSH)

1. ابتدا از دیتابیس فعلی در `phpMyAdmin -> Export` و فایل `.env` داخل پوشه خصوصی یک بکاپ بگیرید.
2. فایل جدید **`cpanel-private.zip`** را در پوشه خصوصی اکسترکت کنید (فایل `.env` و پوشه `storage` شما دست‌نخورده باقی می‌مانند).
3. فایل جدید **`cpanel-public.zip`** را در `public_html` اکسترکت کنید (مواظب باشید `private-path.php` به مسیر پوشه خصوصی شما اشاره کند).
4. آدرس `https://YOUR-DOMAIN.com/update.php` را باز کرده و مقدار `APP_KEY` موجود در فایل `.env` را وارد کنید (یا پس از ورود به پنل با حساب مدیر ارشد، از منوی **تنظیمات سامانه** دکمه **«اجرای بروزرسانی و پاکسازی کش»** را بزنید).
